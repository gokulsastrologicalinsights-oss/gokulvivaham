# Gokul Vivaham — Premium Tamil Matrimony

A scalable, feature-rich matrimony platform built for the Tamil community, designed to connect verified profiles based on modern preferences and traditional astrological matching.

## Tech Stack
- **Framework:** Next.js 15 (App Router, Server Actions, Dynamic Imports)
- **Styling:** Tailwind CSS, Framer Motion
- **Database & Auth:** Supabase (PostgreSQL, Row Level Security, Edge Functions)
- **Data Fetching:** React Query & Next.js cache
- **Payments:** Razorpay API
- **Deployment:** Vercel (Frontend), Supabase Cloud (Backend)

## Core Features
1. **Advanced Search & Filtering:** Filter by Age, Caste, Nakshatra, Location, and Education.
2. **Astrology Compatibility Engine:** Horoscope matching based on Rasi, Nakshatra, and Doshams.
3. **Role-Based Admin Panel:** Dashboard for user management, gallery moderation, reporting, and success story CMS.
4. **Real-time Chat & Notifications:** Communicate seamlessly with connected matches.
5. **Subscription Engine:** Flexible premium plans and payment gateway integration.
